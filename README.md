# AetherTune

AMD laptop-focused Windows tuning suite. Monitoring, GPU tweaks, registry tweaks, performance profiles, startup/services, cleaner, wallpaper/modding, network tweaks.

## Install
Run `installer/install.ps1` as Administrator (or use `installer/AetherTune.exe` portable).

## Run from source
```
pip install -r requirements.txt
python main.py
```
Run as Administrator for HKLM registry/power tweaks.
